# GEMINI.md — Единая база и правила синхронизации проекта «Video» между аккаунтами

> **ВНИМАНИЕ АГЕНТУ:** Пользователь работает над этим проектом с нескольких аккаунтов по очереди (переключается между аккаунтами при исчерпании лимитов). Этот репозиторий / папка — **единая общая база** для всех аккаунтов.

## 1. Обязательный протокол при старте любого чата (на любом аккаунте)
1. **Синхронизация при входе:**
   * Если проект открыт через Git-репозиторий (`nurk008/Video`), первым действием выполни `git pull --rebase origin main 2>/dev/null || true`, чтобы подтянуть свежие изменения со второго аккаунта.
   * Обязательно прочитай файл `PROJECT_STATUS.md` — в нём записано, на каком именно шаге остановился предыдущий аккаунт.
2. **Изучение контекста и строгих правил проекта:**
   * `hanafi_ai_content_rules.md` — **строгие негласные правила продакшна**:
     * Никаких религиозных терминов вслух в самом сценарии (подача как исторический триллер/документалистика), но строгое соблюдение правил внутри:
     * Только достоверные факты и благие качества народа; не упоминать внутренний раскол, междоусобицы, предательства и суеверия/шаманизм.
     * Визуал: строго без детальных лиц крупным планом (использовать силуэты, ракурсы со спины, детали оружия, доспехов, карт, конницы и панорам Степи), без сцен крови и жестокости, без харама.
     * Звук: мощный кинематографичный саунд-дизайн (природа, ветер, копыта, сталь, огонь, низкий голосовой бас / A cappella хор) **без музыкальных инструментов**.
   * `ai_history_channel_guide_and_history.md` — стратегия мультиплатформенного запуска (RU + KZ + EN, Shorts 62–65 сек с бесшовной петлёй Seamless Loop + Long-form 10 мин).
   * `kazakh_history_chat.md` — проверенная историческая база (даты, имена, битвы, традиции).
   * `ordabasy_anyrakai_viral_script.md` — утверждённый сценарий первого выпуска («Ордабасы и Аныракай»).

## 2. Обязательный протокол после каждого шага (автосохранение для другого аккаунта)
После завершения каждого этапа работы (генерация новых сцен, создание озвучки, монтаж видео, написание нового сценария):
1. Сохраняй все созданные файлы **только внутри папки проекта `Video`** (не во временных директориях).
2. Сразу обновляй файл `PROJECT_STATUS.md` (что сделано и какой следующий шаг).
3. Если подключён Git (`origin`), сразу выполняй:
   ```bash
   git add -A && git commit -m "Sync progress" && git push origin main
   ```
   Это гарантирует, что при переходе пользователя на другой аккаунт вся база и последние файлы будут сразу доступны!
